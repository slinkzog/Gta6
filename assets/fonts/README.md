# GTA font (Pricedown)

The pack uses **Pricedown**, the font from the GTA logos, for ALL of its text: headlines, the
neon script lines, subtitles, ticker, phone, HUD and widgets. It is not included here because it's
a licensed font by Typodermic Fonts (Ray Larabie) and can't be redistributed.

## Get it

Download Pricedown from Typodermic Fonts (typodermicfonts.com) or a font site such as dafont.com, and check
the licence for your use (monetised streams count as commercial use).

## Install it (pick one)

**Option A — install on the PC (easiest)**
Double-click the `.otf` / `.ttf` file → **Install**. Restart OBS. Done.

**Option B — put the file in this folder**
Copy the font file here and name it one of:

- `pricedown.otf`
- `pricedown.ttf`
- `pricedown.woff2`
- `pricedown.woff`
- `pricedown bl.otf`  ← the name it usually comes with

Then refresh the browser sources in OBS.

If the font can't be found the pack falls back to Anton automatically, and headlines
shrink to fit whichever font is in use. `index.html` tells you whether the GTA font loaded.
